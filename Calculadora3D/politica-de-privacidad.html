Política de Privacidad - VETA

Calculadora de costes 3D • MaciWeather

Última actualización: 7 de agosto de 2026

En MaciWeather valoramos su privacidad. La aplicación Calculadora de costes 3D - VETA ha sido diseñada bajo principios de privacidad desde el diseño, garantizando que sus datos permanezcan bajo su control total.

1. PRIVACIDAD Y DATOS PERSONALES

Esta aplicación no recopila, almacena ni transmite ningún dato personal de los usuarios. No existen registros de cuenta, ni servidores externos donde se envíe información. Toda la operativa de la aplicación (cálculos, datos de materiales, perfiles de impresión) se realiza y almacena de manera local exclusivamente en el dispositivo del usuario.

2. PUBLICIDAD (Google AdMob)

La aplicación integra el SDK de Google AdMob para permitir su descarga gratuita. Este servicio de publicidad de terceros puede recopilar automáticamente ciertos metadatos técnicos del dispositivo para mostrar anuncios contextuales, tales como:

  • ID de publicidad (AAID).
  • Modelo del dispositivo y sistema operativo.
  • Información básica de uso técnico con fines estadísticos y de rendimiento publicitario.

Puede consultar cómo Google trata estos datos en su Política de Privacidad de Google.

3. CONTROL DE DATOS

Dado que la aplicación funciona exclusivamente en local, no existe una base de datos centralizada. Si el usuario desea eliminar cualquier rastro de la aplicación, basta con desinstalarla del dispositivo. Al desinstalar la aplicación, todos los datos locales se eliminan automáticamente de forma irreversible por el sistema operativo.

4. CONTACTO

Si tiene alguna pregunta sobre esta política, puede ponerse en contacto con el desarrollador a través del perfil de GitHub donde se aloja esta documentación o mediante los canales de soporte disponibles en la Google Play Store.
